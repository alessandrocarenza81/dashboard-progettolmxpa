Scheda di approfondimento

Hardware, software e file: i concetti chiave in breve

  • Hardware = le parti fisiche del computer (CPU, RAM, disco, monitor, periferiche...). Software = i programmi che lo fanno funzionare.
  • Il software di sistema (es. il sistema operativo) gestisce l'hardware e fa "da regista"; il software applicativo (es. un elaboratore di testi) serve a svolgere compiti specifici.
  • RAM = memoria temporanea di lavoro (si svuota allo spegnimento); disco/SSD = memoria permanente (conserva i dati anche da spento).
  • Le cartelle si possono annidare l'una dentro l'altra creando una struttura "ad albero": pensare prima a un criterio (per anno, per progetto, per cliente...) aiuta a non perdersi.
  • L'estensione di un file (es. .pdf, .docx, .jpg) indica il tipo di contenuto e, di solito, con quale programma si apre.
  • Il Cestino conserva temporaneamente i file cancellati: si può quasi sempre ripristinare ciò che si elimina per sbaglio, finché non si svuota.
